These are complete TypeScript examples that complement the [docs playground](/playground).
Each one is a complete, self-contained program: it imports from
`@crstnmac/zeropdf`, builds a document, and `export default`s it. Paste any of
them into the playground (or a local script) and run it as-is.

The snippets below are embedded directly from the repository's sample files.

<Callout type="idea" title="Run these">

Open the [playground](/playground) to experiment with Document JSON, or copy a
TypeScript snippet into your own project. For non-browser usage,
swap `export default doc;` for `await writeFile("out.pdf", doc.toUint8Array());`.

</Callout>

## Rich text & layout

Document-wide text defaults, registered font families, `mm()` units, inline
rich text with `underline`/`strike`, justified alignment, vertical alignment,
shape helpers (`rect`, `circle`), named colors, and `richParagraph` template
blocks. The flowing portion is rendered with `renderTemplate()`.

<include lang="ts">../../../examples/website/samples/rich-text-and-layout.ts</include>

## Text formatting

Superscript/subscript and baseline `rise`, render modes (`stroke` outline,
`fillStroke`, `invisible`), `horizontalScaling` to condense/expand glyphs, and
inline `highlight` — shown on template paragraphs and rich-text runs. See
[Text and Fonts](/guide/text-and-fonts#superscript-subscript-and-baseline-shift).

<include lang="ts">../../../examples/website/samples/text-formatting.ts</include>

## Google Fonts

Fetch several Google Fonts (Inter, Geist, Instrument Serif with an italic face, and Bitcount Grid Single) and embed them as font families. In Node, use `loadGoogleFont("Inter", { weight: 700 })`; this browser sample fetches ready-made `.ttf` files from the CORS-enabled `@expo-google-fonts` packages on jsDelivr instead, because the Google Fonts API serves woff2 to browsers, which the engine cannot decode. See [Text and Fonts → Google Fonts](/guide/text-and-fonts#google-fonts).

<include lang="ts">../../../examples/website/samples/google-fonts.ts</include>

## Browser AES encryption

AES-256 encrypt a document entirely client-side — no Node runtime. The library
uses a built-in AES/SHA-2 fallback when `node:crypto` is unavailable, so the
output opens with the same password in any reader. See
[Encryption and Signatures → Browser support](/guide/encryption-and-signatures#browser-support).
