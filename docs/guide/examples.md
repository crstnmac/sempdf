# Examples

These are the starter snippets bundled with the [live playground](https://zeropdfplayground.zeropdf.net/).
Each one is a complete, self-contained program: it imports from
`@zeropdf/zeropdf-pdf`, builds a document, and `export default`s it. Paste any of
them into the playground (or a local script) and run it as-is.

The snippets below are embedded directly from the playground's sample files, so
the code here and the code you see in the playground are always identical.

::: tip Run these
Open the [playground](https://zeropdfplayground.zeropdf.net/) and pick a sample from
the dropdown, or copy a snippet into your own project. For non-browser usage,
swap `export default doc;` for `await writeFile("out.pdf", doc.toUint8Array());`.
:::

## Google Fonts

Fetch several Google Fonts (Inter, Geist, Instrument Serif with an italic face, and Bitcount Grid Single) and embed them as font families. In Node, use `loadGoogleFont("Inter", { weight: 700 })`; this browser sample fetches ready-made `.ttf` files from the CORS-enabled `@expo-google-fonts` packages on jsDelivr instead, because the Google Fonts API serves woff2 to browsers, which the engine cannot decode. See [Text and Fonts → Google Fonts](./text-and-fonts#google-fonts).

<<< ../../examples/website/samples/google-fonts.ts{ts}

## Browser AES encryption

AES-256 encrypt a document entirely client-side — no Node runtime. The library
uses a built-in AES/SHA-2 fallback when `node:crypto` is unavailable, so the
output opens with the same password in any reader. See
[Encryption and Signatures → Browser support](./encryption-and-signatures#browser-support).
